STUDENT RESULT MANAGER - POSTGRESQL WINDOWS SETUP

1. Requirements
   - Node.js 18+ (your Node.js 25 is fine)
   - PostgreSQL installed and running
   - pgAdmin 4 is optional; it is useful for viewing the database

2. Create the database
   In pgAdmin 4:
   - Connect to your PostgreSQL server.
   - Right-click Databases -> Create -> Database.
   - Database name: student_result_manager
   - Save.

   Or in Query Tool:
     CREATE DATABASE student_result_manager;

3. Configure environment
   Copy .env.example to .env and set your PostgreSQL password:
     PORT=5000
     PGHOST=localhost
     PGPORT=5432
     PGDATABASE=student_result_manager
     PGUSER=postgres
     PGPASSWORD=YOUR_POSTGRES_PASSWORD
     JWT_SECRET=use_a_long_random_secret

4. Install packages
     npm install

5. Seed demo data
     npm run seed

6. Start
     npm start

7. Open
     http://localhost:5000

Demo teacher:
   teacher@example.com / Teacher@123
Demo student:
   student@example.com / Student@123

The server creates the required tables automatically when it starts. The seed command resets the project tables and inserts demo data, so only run it when you want to reset the demo database.
